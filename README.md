
# 📄 PDF Merger Pro

A fast, secure, local web app to merge PDFs, extract specific pages, and convert merged text into MS Word format.

## ✨ Features
* **Smart Extraction:** Select exactly how many pages to extract from the Top, Middle, or Bottom of each file.
* **Dual Export:** Download the final document as a standard PDF or extract the text to a Word (`.docx`) file.
* **100% Local & Private:** All processing happens on your machine. No files are uploaded to the cloud.

## 🚀 Quick Start

**1. Setup Environment & Install**
Open your terminal in the project folder and run:
```bash
python -m venv venv

# Activate on Windows:
venv\Scripts\activate
# Activate on Mac/Linux:
source venv/bin/activate

pip install -r requirements.txt

```

**2. Run the Application**

```bash
streamlit run web_app/web_merger.py

```

## 🛠️ Usage

1. Drag and drop your PDFs into the web interface.
2. Configure the page extraction settings for each file.
3. Click **Merge PDFs Now**.
4. Download your new PDF or Word document!
